# 📓 Notebook Studio • Digital Ruled Notebook & A4 Templates

> **Sổ tay ghi chép số cá nhân cao cấp mô phỏng sổ thật trên bàn làm việc (A4 Real-Feel Desk Spread)** — Hỗ trợ 3 mẫu trang kinh điển quốc tế (**Cornell Notes**, **Work & Project Log**, **Ruled Classic**), lật trang 3D chân thực, dải lụa đỏ chuyển trang thông minh, và hệ thống typography song ngữ CJK / Latinh tiếp xúc đường kẻ chính xác tuyệt đối.

---

## ✨ Tính Năng Nổi Bật (Key Features)

### 1. Trải Nghiệm Mở Sổ & Lật Trang 3D Chân Thực
- **Bàn làm việc A4 (Desk Workspace)**: Mô phỏng cuốn sổ thực tế mở rộng 2 trang song song hoặc 1 trang đơn lẻ trên mặt bàn gỗ tối giản.
- **Lật trang 3D sống động (Page Flip Physics)**: Hiệu ứng chuyển trang mượt mà 60fps với độ cong trang giấy và đổ bóng chiều sâu.
- **Dải lụa đỏ đánh dấu trang (Silk Focus Ribbon)**: Bấm vào dải lụa để chuyển đổi nhanh tiêu điểm con trỏ soạn thảo giữa trang Trái và trang Phải.
- **Thu phóng linh hoạt (Zoom & Fit)**: Zoom tự do từ 30% đến 350% bằng nút bấm, phím tắt hoặc con lăn chuột (`Ctrl + Wheel`), đi kèm hai chế độ hiển thị tối ưu: **Fit Page** (vừa vặn chiều cao) và **Fit Width** (vừa vặn bề ngang).

### 2. Ba Mẫu Trang Tiêu Chuẩn Quốc Tế (Vector Page Templates)
- **Cornell Notes**: Phân chia khoa học theo phương pháp Cornell kinh điển gồm cột từ khóa (**Cues & Questions**), vùng ghi chép chính (**Notes**), khung tóm tắt cô đọng (**Summary & Synthesis**) và footer học thuật.
- **Work & Project Log**: Quản lý dự án chuyên nghiệp với mục tiêu, ngày tháng, hạn chót, huy hiệu trạng thái (**TODO / WIP / DONE**), hai cột nội dung (**Agenda & Decisions**, **Notes & Discussions**), và danh sách công việc cần làm (**Action Items Checklist**) tích hợp checkbox tương tác thời gian thực.
- **Ruled Classic & Freeform**: Mặt giấy kẻ ngang truyền thống hỗ trợ ghi chép tự do, nhật ký cá nhân, sáng tác ý tưởng với bước dòng chuẩn 28px.

### 3. Hệ Thống Soạn Thảo & Định Dạng Phong Phú (Universal Toolbar)
- **Kiểu chữ & Cỡ chữ**: Hỗ trợ 3 bộ phông tuyển chọn (**Jakarta Sans**, **Cormorant Serif**, **JetBrains Mono**), tăng giảm cỡ chữ nhanh hoặc chọn chính xác từ 11px đến 28px.
- **Định dạng văn bản**: Đậm (`Bold`), Nghiêng (`Italic`), Gạch chân (`Underline`), Gạch ngang (`Strike`), Huy hiệu viền tròn (`Pill Badge`).
- **Màu sắc & Dạ quang**: Bảng chọn màu chữ và màu nền highlight pastel tinh tế.
- **Cấu trúc đoạn**: Tiêu đề H1, H2, H3, Danh sách gạch đầu dòng (`Bullet`), Đánh số tự động (`Numbered`), Hộp kiểm công việc (`Todo`), Đoạn trích dẫn (`Quote`), Khối mã lệnh (`Code block`), Đường kẻ phân cách (`Divider`).
- **Khoảng cách dòng kẻ (Ruled Step)**: Cố định bước dòng 24px, 28px, 32px, 36px, 42px hoặc tắt đường kẻ tự do.

### 4. Chế Độ Toàn Màn Hình Không Xao Nhãng (Distraction-Free Fullscreen)
- Toàn màn hình góc nhìn rộng qua phím `F11` hoặc `Alt + Enter`.
- **Thanh Rail điều khiển bên trái (Left Rail)**: Hiển thị số trang hiện tại, nút lật trang, nút thêm trang mới, chuyển đổi mẫu trang, nút thu phóng và công cụ mở ngăn kéo định dạng nổi (`Floating Tools Drawer`).

### 5. Xuất Bản & In Ấn Chuẩn Vector (Print / Export PDF)
- Tự động sinh trang bìa hoàng gia A4 sang trọng với khung viền hoa văn cổ điển, tên tác giả, danh mục và tổng số trang.
- Định dạng in ấn `@media print` sắc nét chuẩn vector, hỗ trợ in toàn bộ cuốn sổ kèm bìa hoặc chỉ in nội dung trang.

### 6. Quản Lý Thư Viện Sổ (Digital Library & Shelves)
- Tủ sách trực quan với bìa da sang trọng, tinh giản hoàn toàn các nút thao tác thừa trên bìa sổ để tập trung trải nghiệm mở sổ tự nhiên.
- Tìm kiếm toàn văn thông minh (tìm kiếm tức thì trong tên sổ, tác giả, ghi chú và danh sách việc cần làm).
- Phân loại danh mục động qua bộ lọc tinh giản, tự động ưu tiên sổ cập nhật gần nhất.
- Tính năng xóa sổ an toàn nằm trong màn hình chi tiết (Detail / Reader View) với hộp thoại xác nhận chuyên biệt (Confirmation Modal) cảnh báo rõ số lượng trang bị xóa và thông báo hoàn tác nhanh (Undo Toast).

### 7. Lưu Trữ Tự Động & Hỗ Trợ Offline PWA
- Tự động lưu dữ liệu qua `localStorage` với cơ chế debounce chống nghẽn hiệu năng (chuẩn bị sẵn sàng tích hợp DB & Auth backend).
- Quản lý phiên bản dữ liệu tự động (Schema Migration) an toàn và tối ưu.
- PWA Manifest và Service Worker v7 hoạt động mượt mà khi không có kết nối Internet.

## 🖋️ Quy Chuẩn Căn Chỉnh Typography (Typographic Invariants)

Hệ thống tuân thủ nghiêm ngặt 3 quy tắc quang học bất biến nhằm mang lại trải nghiệm viết tay tự nhiên như trên giấy thật:

| Đối tượng | Quy tắc hiển thị | Cấu hình kỹ thuật |
| :--- | :--- | :--- |
| **Chữ Latin / Tiếng Việt / Pinyin** | Toàn bộ chân chữ (baseline) tiếp xúc chuẩn xác trên đường kẻ ngang dưới | `background-position: 0 -6px` trên `.template-writing-area` và `.ruled-canvas-text` |
| **Chữ Hán (CJK Characters)** | Tự động nằm ở **chính giữa ô kẻ ngang**, kích thước to hơn và nét Khải Thư thanh đậm | Tự động bọc trong `<span class="hanzi-cjk">`: `font-size: 1.3em`, `position: relative; top: -4.5px;`, font `Kaiti SC` / `STKaiti` / `KaiTi` |
| **Khóa chiều cao dòng (Line-height)** | Tuyệt đối không để line-box bị giãn khi gõ đan xen đa ngôn ngữ | `line-height: var(--notebook-line-height, 28px) !important; min-height: 28px;` và `vertical-align: 0` trên chữ Hán |

## 🚀 Cài Đặt & Khởi Chạy

### Cài đặt nhanh (One-Line Install)

```bash
curl -fsSL "https://github.com/thaonv7995/notebook/releases/latest/download/install.sh" | bash -s -- "thaonv7995/notebook"
```

Script sẽ tự động:
- ✅ Tải release mới nhất
- ✅ Cài đặt dependencies (production)
- ✅ Tạo tài khoản `admin@notebook.com` với **mật khẩu ngẫu nhiên**
- ✅ Sinh JWT secret
- ✅ Khởi động server tại `http://localhost:27972`

### Cập nhật phiên bản (Update)

```bash
curl -fsSL "https://github.com/thaonv7995/notebook/releases/latest/download/install.sh" | bash -s -- "thaonv7995/notebook" update
```

> Dữ liệu, mật khẩu và cấu hình `.env` được **giữ nguyên** khi cập nhật.

### Gỡ cài đặt (Uninstall)

```bash
curl -fsSL "https://github.com/thaonv7995/notebook/releases/latest/download/install.sh" | bash -s -- "thaonv7995/notebook" uninstall
```

> Dữ liệu sẽ được **backup** vào `~/notebook-studio-backup-*` trước khi xóa.

### Cài đặt thủ công (Manual Setup)

```bash
# 1. Clone & cài đặt
git clone https://github.com/thaonv7995/notebook.git notebook-studio
cd notebook-studio
npm install

# 2. Tạo file cấu hình
cp .env.example .env    # Hoặc tạo thủ công (xem bên dưới)

# 3. Build frontend
npm run build

# 4. Chạy production server
npm start               # → http://localhost:27972
```

### Cấu hình `.env`

```env
PORT=27972
JWT_SECRET=your-random-secret-at-least-32-chars
ADMIN_USERNAME=admin@notebook.com
ADMIN_PASSWORD=your-secure-password
NODE_ENV=production
```

> Server tự động tạo tài khoản admin từ `.env` khi khởi động lần đầu.

### Chế độ phát triển (Development)

```bash
npm run dev    # Chạy đồng thời Vite HMR (port 27973) + Express API (port 27972)
```

### Kiến trúc Server

```text
Server (Express + JSON DB)
├── POST   /api/auth/login      → Đăng nhập, nhận JWT cookie
├── POST   /api/auth/logout     → Đăng xuất, xóa cookie
├── GET    /api/auth/me         → Kiểm tra phiên đăng nhập
├── GET    /api/notebooks       → Tải toàn bộ thư viện
├── PUT    /api/notebooks/sync  → Đồng bộ toàn bộ dữ liệu
└── DELETE /api/notebooks/:id   → Xóa cuốn sổ
```

- **Auth**: JWT (bcrypt hash) lưu trong httpOnly cookie, hết hạn 7 ngày
- **Database**: `data/db.json` — JSON file với atomic writes
- **Frontend**: Build tĩnh từ `dist/`, serve bởi Express

## ⌨️ Bảng Phím Tắt Tiện Dụng (Keyboard Shortcuts)

| Phím tắt | Chức năng | Phạm vi |
| :--- | :--- | :--- |
| `Ctrl/Cmd + S` | Lưu tức thì dữ liệu trang hiện tại | Toàn ứng dụng / Trong ô soạn thảo |
| `Ctrl/Cmd + \` | Thu gọn / Mở rộng thanh công cụ định dạng | Toàn ứng dụng |
| `F11` hoặc `Alt + Enter` | Bật / Tắt chế độ toàn màn hình (Distraction-free) | Toàn ứng dụng |
| `Ctrl/Cmd + =` / `+` | Phóng to bàn làm việc (Zoom In) | Trình đọc sách |
| `Ctrl/Cmd + -` / `_` | Thu nhỏ bàn làm việc (Zoom Out) | Trình đọc sách |
| `Ctrl/Cmd + 0` | Đưa tỷ lệ zoom về 100% chuẩn | Trình đọc sách |
| `Ctrl + Con lăn chuột` | Phóng to / Thu nhỏ trực quan theo vị trí trỏ | Trình đọc sách |
| `Mũi tên Trái / Phải` | Lật trang Lùi / Tiến | Khi không focus trong ô soạn thảo |
| `Ctrl/Cmd + B` | In đậm văn bản đang chọn | Ô soạn thảo / Textarea |
| `Ctrl/Cmd + I` | In nghiêng văn bản đang chọn | Ô soạn thảo / Textarea |
| `Ctrl/Cmd + U` | Gạch chân văn bản đang chọn | Ô soạn thảo / Textarea |
| `Escape` | Đóng menu nổi, đóng hộp thoại modal hoặc thoát Fullscreen | Toàn ứng dụng |
| **Bấm Dải lụa đỏ** | Chuyển đổi con trỏ soạn thảo nhanh giữa trang Trái và trang Phải | Trình đọc sách 2 trang |
